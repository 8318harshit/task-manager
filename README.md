# Task Tracker

## About
A simple task tracker made with Next.js.

## Features
- Add tasks with a title and description
- Mark tasks as completed or pending
- Delete tasks
- See task counts
- Filter tasks
- Keep tasks after refreshing with localStorage

## Tech Stack
- Next.js
- React
- JavaScript
- CSS

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
